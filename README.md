# Task 4: Feature Encoding & Scaling

## Objective
To preprocess the Adult Income dataset using feature encoding and scaling techniques for machine learning.

## Dataset
Adult Income Dataset used to predict income category (<=50K or >50K).

## Tools Used
Python, Pandas, Jupyter Notebook

## Steps
- Loaded dataset and assigned column names
- Cleaned extra spaces in data
- Identified categorical and numerical features
- Applied Label Encoding to target variable
- Applied One-Hot Encoding to categorical features
- Scaled numerical features
- Saved the processed dataset

## Output
adult_income_processed.csv
